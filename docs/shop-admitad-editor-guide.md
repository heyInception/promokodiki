# Магазины: описания, связи и партнёрские ссылки

## Подготовка Admitad

OAuth-токен должен быть перевыпущен с правом `deeplink_generator`. Плагин уже запрашивает это право вместе с существующими scope. Без повторной авторизации генератор получит 403, отметит кампанию как неподдерживаемую и оставит прямую ссылку на магазин.

## Редактирование магазина

Откройте **Промокоды → Магазины → Изменить магазин**. В секции **Описание из Admitad** доступны:

- `Campaign ID Admitad` — только ID кампании, присутствующей в локальном справочнике; один ID нельзя назначить двум магазинам;
- исходное очищенное описание Admitad — обновляется синхронизацией и недоступно для ручной правки;
- **Описание для сайта** — ручная версия, которую синхронизация не перезаписывает; кнопка копирования переносит исходный текст в редактор, а сброс возвращает автоматический fallback;
- адрес, телефон, почта и сайт — обычные редактируемые поля; API заполняет только пустые сайт, телефон и почту, адрес не угадывается;
- ручная партнёрская ссылка и состояние автоматического deeplink.

На сайте приоритет описания: ручное → очищенное Admitad → прежнее метаполе → стандартное описание WordPress. Ссылки вместе с их текстом и служебные партнёрские разделы из исходного описания удаляются.

## Магазины без связи

Откройте **Промокоды → Магазины без связи**. Таблица показывает существующие магазины с отсутствующим, некорректным, неизвестным или дублирующимся Campaign ID. Кампанию можно найти по названию в локальном справочнике, указать ID и связать магазин. Сохранение сразу переносит локальные данные профиля и ставит deeplink в фоновую очередь; сетевого запроса в этом POST нет.

## Deeplink

На странице **Магазины без связи** сначала нажмите **Предварительный просмотр**: будут показаны числа `создать`, `обновить`, `без изменений`, `не поддерживается` и `некорректно`. Затем нажмите **Поставить в очередь**. WP-Cron обрабатывает не более 20 магазинов за запуск.

Публичная страница никогда не вызывает Admitad API. Приоритет URL: ручная партнёрская ссылка → готовый автоматический deeplink → прямой сайт. Пользователь видит обычный домен магазина, а переход получает `rel="nofollow sponsored noopener noreferrer"`. Временная ошибка не стирает ранее рабочий deeplink.

Для ручного запуска очереди:

```powershell
studio wp cron event run promokodiki_admitad_deeplink_batch
```

## Изображения

Логотипы остаются в управляемой схеме: ограничение 2 МиБ, JPEG/PNG/WebP и переиспользование по SHA-256. Повторная синхронизация не создаёт копии одного изображения. Изображения внутри `.promocodes__imgs` не изменяются.
